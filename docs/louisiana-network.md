# The Louisiana Network

Implemented directly in the existing Gent Distribution Co. homepage. The original local edits were preserved and refined; no package-shaped terrain nodes remain in the hero.

## Rendering and motion

- Server-rendered dimensional basin artwork with live SVG distribution paths aligned to its waterways. The illustration is a brand environment, not a geographic survey or claim of active coverage.
- Lafayette / Acadiana is the persistent origin. Six destination categories: makers, retailers, hospitality, restaurants, specialty stores, barbershops. A dotted continuation suggests future reach.
- Obsidian, deep green and exact luxury gold #C4912F. Existing brand typography, navigation, collection and subsequent scenes retained.
- Desktop uses the existing GSAP film: network wake-up, finite traveling product pulses, mist parallax, camera approach to Lafayette, origin story, then the Gent Standard chamber. Scrolling backward reverses the sequence.
- Tablet and phone use native document flow with a smaller scroll-driven camera descent. Short viewports, paused motion, reduced motion and absent JavaScript show the complete static network and all content.
- No WebGL dependency, canvas, per-frame React updates or perpetual particle animation. One 172,428-byte WebP environmental asset; responsive Next Image delivery and preload. Finite SVG path and wrapper transforms provide progressive enhancement.

## Asset provenance

Asset: public/images/louisiana-network.webp (1536 × 1024). Created with the built-in image-generation tool, then converted lossily to WebP using Sharp. Generated source retained in the tool's output directory. The environmental asset contains no type or network symbols; all typography and network animation are live code.
